# Автошкола HR → UA — словник, дорожні знаки, тренувальний іспит

Готовий статичний сайт для **GitHub Pages**, без Node.js, фреймворків, збірки або бази даних.

## Структура

- `index.html` — головна сторінка
- `slovnyk/index.html` — словник (323 терміни)
- `znaky/index.html` — дорожні знаки та розмітка (210 карток)
- `ispyt/index.html` — тренувальний іспит Wiki95 (38 питань / 45 хв / 4 питання про пріоритет)
- `ispyt/questions/` — 748 WebP-зображень оригінальних питань
- `ispyt/data.js`, `ispyt/app.js`, `ispyt/styles.css` — ключі відповідей, логіка і стилі іспиту
- `assets/site.css` — адаптивний інтерфейс
- `assets/app.js` — пошук, фільтри й обране
- `assets/diagrams/` — навчальні схеми для елементів, для яких не вдалося підтвердити точний SVG у Wikimedia Commons
- `manifest.webmanifest` — базові параметри для додавання на головний екран

## Оновлення наявного GitHub Pages

Цей пакет створено для наявного репозиторію `olegdatsenko/autoskola-hr-ua`. Не створюйте новий репозиторій та Umami Website ID.

1. Розпакуйте ZIP і помістіть **вміст** (включно з прихованою `.github/`) у корінь **того самого** репозиторію. Старі файли й папки, яких немає в пакеті, не видаляйте: якщо з часу підготовки пакетів були нові зміни, їх потрібно зберегти.
2. Збережіть чинний workflow `.github/workflows/deploy.yml` — `Publish Autoškola HR-UA`.
3. Перевірте Actions → Publish Autoškola HR-UA, дочекайтеся успішного деплою.
4. Відкрийте `https://olegdatsenko.github.io/autoskola-hr-ua/ispyt/` і перевірте навігацію.

Не завантажуйте архів ZIP в репозиторій одним файлом: потрібен **його розпакований вміст**. Актуальні зміни в репозиторії до публікації потрібно звіряти, щоб не перезаписати чужі або власні нові правки.

Іспит використовує початкові незмінені зображення PDF, підвантажує **лише поточну сторінку**, зберігає відповіді та історію помилок тільки в браузері, без серверу. Ключ Wiki95 обмежує інтерфейс, **але не захищає відкриті файли GitHub**.

## Працює без сторонніх сервісів для пошуку

Пошук та фільтри виконуються локально в браузері. Обране зберігається локально на пристрої (localStorage), між пристроями не синхронізується.

## Зображення: обмеження та атрибуція

- Більшість карток у вихідному коді використовує зовнішні SVG із **Wikimedia Commons**. Рекомендований GitHub Actions workflow намагається локально скопіювати ці SVG під час публікації. Не всі копії гарантовано вдасться отримати. Це **не повністю автономний офлайн-сайт**.
- Деякі оригінальні посилання були неправильними (`B30.svg`, `B38.svg`, `C11.svg`, `C12.svg`, `C22.svg`, `C23.svg`, `E02.svg`, `E14.svg`, `E15.svg`). Коректні варіанти підставлені там, де їх вдалося підтвердити; E02, E14 та E15 переведені на позначені навчальні схеми, оскільки однойменні Wikimedia-файли позначають інші знаки. На картках позначено, коли показано варіант чи навчальну схему.
- Для D01–D04, E02, E09–E11, E14–E15, E17–E18 і C96 використані **авторські схематичні ілюстрації**, які допомагають відрізнити типи знаків, але не є точним нормативним зображенням. За точним виглядом звертайтеся до законодавчого джерела.
- Якщо зовнішній SVG заблокований, замість коду показується нейтральна іконка з повідомленням. Це не означає, що знак перевірений або зображений точно.
- Для кожного зображення є посилання **«Джерело»** на Commons або нормативний документ. У Wikimedia Commons умови використання відрізняються залежно від файлу; дотримуйтеся вказаних там умов (зокрема CC BY-SA або public domain).
- Нормативний текст: [Pravilnik o prometnim znakovima, signalizaciji i opremi na cestama, NN 92/2019](https://narodne-novine.nn.hr/clanci/sluzbeni/2019_09_92_1823.html). Перевіряйте актуальні зміни до нормативного акта.

## Контент та редакційні примітки

Словник створений на основі аналізу 748 навчальних тестових питань; окремий розділ «Іспит» відтворює ці оригінальні сторінки. Власність і право на публічне поширення PDF-матеріалів треба перевірити до публікації. Переклади, оцінки складності й коментарі є допоміжними навчальними матеріалами, не мають статусу офіційних пояснень.

До публічного використання рекомендована редакційна перевірка термінології, юридичних коментарів та всіх зображень на відповідність чинному Pravilnik. **Роботу на фізичному iPhone не перевірено.**
